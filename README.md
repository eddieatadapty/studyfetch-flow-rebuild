# StudyFetch Growth Audit

**Live → https://eddieatadapty.github.io/studyfetch-flow-rebuild/**

Five ideas to turn more StudyFetch users into subscribers, each built into a clickable version of StudyFetch's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | A real first result before the price | +10–20% CR to purchase |
| 02 | Name their answer on the paywall | +15–20% CR to purchase |
| 03 | Ask for the camera when they use it | +10–15% CR to purchase |
| 04 | One button, one price: the App Store’s | +3–8% CR to purchase |
| 05 | Proof that fits who they are | +5–10% CR to purchase |

Every price, rating and feature comes from StudyFetch's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for StudyFetch. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
